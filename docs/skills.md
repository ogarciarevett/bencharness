# Installed skills benchmark

`python3 -m bench.skills` compares the same task with and without each of the 11 requested Matt Pocock skills. Both sides use the existing restricted model seam: gpt-6.1-sol, medium effort, standard subscription tier, 180 active seconds per side, offline commands, no host skills, extensions or delegation. Pair order alternates across skills. Each UTC day gets a fresh comparison; completed sides resume without another call.

The installed plugin must match `bench/skills-pin.json`: version 1.3.1, commit `49dd158d1076134a641b33efb035946536778336`, MIT license and exact file hashes. Only benchmark metadata is committed. Skill text and its supporting files are copied from the installed plugin into the treatment workspace; the baseline receives the same task and fixture without those files. No plugin code, hooks or servers are run.

Results are written to `results/skills/YYYY-MM-DD.json` and a Markdown table alongside it. Private calls, stderr and per-side receipts remain in `runs/skills-*/`. The nightly verifier compares committed results with their private receipt and regenerates the table. Existing daily records are immutable.

The reported pass rate is the fraction of predefined checks passed in **one task per skill**, with no statistical significance claim. Diagnosing-bugs and TDD use executable functional assertions in the existing adapter sandbox. Other tasks use artifact/term checks; these measure basic deliverable coverage, not design quality, interview usefulness, browser behavior or wizard safety. Tokens include input plus output; cached input is already included in input and is not added twice. Delta is skill minus baseline, in percentage points. Time includes seam bookkeeping. This is an initial smoke benchmark, not a general ranking of skills. Skills requiring delegation are evaluated serially because the harness disables sub-agents.

The start gate requires load below 20 and swap below 8 GB, or swap below 10 GB with free memory above 45%; free memory must be at least 30%. The shared `/Volumes/Studio/.cache/local-ci-build.lock` serializes this with other local builds. Existing seam checks stop calls conservatively at its start thresholds, which are stricter than the hard-pause limits. Host deferral writes no result; model or setup errors exit nonzero and write no completed comparison. The old trial queue runs afterward and retains its independent dependency checks.

During rollout, `BENCH_SKILLS_ROOT` may point at the reviewed source checkout while `--workspace` writes results and receipts to the nightly checkout. Once merged, the nightly checkout supplies its own runner. Revert the scheduler launcher to the original checkout to undo rollout; the feature can be removed by reverting its commit, preserving prior result files.
